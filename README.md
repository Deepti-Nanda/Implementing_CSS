# Implementing_CSS (About Me) — Personal Profile Webpage

> A modern, responsive, and visually appealing **About Me webpage** built with HTML5 and CSS3.

🌐 **Live Demo:** [View Website](https://deepti-nanda.github.io/Implementing_CSS/)

---

## 💫 About the Project

This project is a simple yet attractive personal profile webpage created to practice and demonstrate fundamental **HTML and CSS** concepts.

The webpage presents my introduction, skills, interests, and social media profiles through a clean **profile-card design** with modern styling and interactive effects.

---

## 🎨 Features

* 👤 Modern profile card design
* 🌈 Gradient background
* ✨ Smooth hover animations
* 🏷️ Interactive skill badges
* 🔗 LinkedIn & GitHub social links
* 📱 Fully responsive layout
* 💎 Rounded cards and modern shadows
* 🖥️ Works across desktop, tablet, and mobile devices

---

## 🛠️ Technologies Used

| Technology   | Purpose                                         |
| ------------ | ----------------------------------------------- |
| 🌐 **HTML5** | Page structure and content                      |
| 🎨 **CSS3**  | Styling, layout, animations, and responsiveness |
